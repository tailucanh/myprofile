Giới thiệu

Tôi là Game Developer với hơn 3 năm làm việc tại Hà Nội, hiện ở DigiNext. Nền tảng của tôi là chuyên ngành Lập trình Mobile tại Cao đẳng FPT Polytechnic (điểm trung bình 8.6/10), nên ngoài game tôi vẫn làm app và server: một app gọi món chạy trên điện thoại thật, một trang bán hàng có server riêng, một công cụ giúp lập trình viên đỡ tốn thời gian.

Ngoài giờ học, tôi tham gia các cuộc thi lập trình như FPT Edu Hackathon và F-Talent Code, và tự học qua Bro Code, freeCodeCamp, W3Schools cùng mã nguồn trên GitHub.

Kỹ năng

Bốn mảng tôi đã làm qua công việc và dự án thật, kèm công nghệ dùng trong từng mảng.

  • Phát triển game

    Công việc chính từ năm 2023, qua ba công ty game tại Hà Nội. Dự án cá nhân làm trên Unity bằng C#: animation, hiệu ứng hạt, vật lý, màn chơi.

    • Unity
    • C#

  • Phát triển ứng dụng di động

    Làm app Android theo nghiệp vụ thực tế: đăng nhập, quản lý dữ liệu, thống kê, in hóa đơn. Dùng được cả Flutter và React Native.

    • Java Android
    • Flutter
    • React Native
    • SQLite
    • Firebase

  • Backend và web

    Viết REST API với Node.js/Express, kết nối MongoDB; làm giao diện web với HTML, CSS, JavaScript, Bootstrap, jQuery. Gần đây viết thêm TypeScript.

    • Node.js
    • Express
    • MongoDB
    • TypeScript
    • HTML/CSS/JS

  • Thiết kế giao diện app

    Thiết kế màn hình trên Figma rồi dựng lại bằng layout XML; chỉnh ảnh cơ bản bằng Photoshop.

    • Figma
    • XML layout
    • Photoshop

Công cụ hằng ngày: Git, GitHub, Android Studio, VS Code, Figma, tin học văn phòng.

Dự án mã nguồn mở, 2026

offload-mcp-server

MCP server cho Claude Code: giao việc đọc nặng (quét nhiều file, lọc log dài, kiểm kê cả thư mục) cho một agent CLI chạy nền, rồi chỉ đọc lại bản báo cáo ngắn. Nhờ vậy model chính đọc ít token hơn hẳn.

  • TypeScript
  • Node.js
  • MCP SDK

Phát hành trên npm và MCP Registry, giấy phép MIT.
